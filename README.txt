北海道研修旅行2026｜写真背景・横スクロール行程表 版

公開用サイト一式（HTML×4、CSS、JavaScript、assets/画像4点）

1. このZIPを展開する。
2. index.html / guide.html / stay.html / safety.html / style.css / script.js と、assets フォルダをセットでGitHubのリポジトリ直下に置く。
3. GitHub Pages の設定が main / (root) になっていれば、数分後に更新される。
4. ブラウザで表示が古い場合は Ctrl+Shift+R で更新。

主な更新：
・ページ上部「次の行程」の自動表示（閲覧時刻から判定、2026年の日程に対応）
・コース切替に伴う「次の行程」の更新
・30分刻みの横スクロールタイムライン（左右ボタン・スワイプ対応）
・行程カード内のイメージ写真
・訪問先は写真をメインに、説明を半透明パネルで常時表示
・雪山写真をページ背景に設定

画像について：
・assets 内の冬山画像は生成されたイメージで、実在の観光地の記録写真ではありません。
・観光地などの画像は従来の Unsplash CDN を参照しています。表示できない場合は assets 内の冬山イメージに切り替わります。
・観光地や施設の実景と誤認しないよう、サイト内に「写真はイメージ」と記載しています。

行程情報：2026年10月5日付旅行会社行程表に基づく。学校・旅行会社の最新案内を優先。
2025年度のしおりは2026年度の確定事項ではありません。
個人の名簿、部屋割り、未公開のホテル原材料PDFは同梱していません。
