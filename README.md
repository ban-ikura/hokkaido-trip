# 北海道研修旅行 2026 — 公開サイト完成版

2026年12月7日〜10日の北海道研修旅行サイトです。**2026年10月5日付の行程資料と2026年度のホテル提供資料**を優先して作成し、昨年度のしおりは注意事項の参考にしています。

## 更新内容

- 暗い冬山の背景画像をCSS内に埋め込み、PC・スマホで安定表示
- 日本語の端末標準フォントを整理。外部フォントの読み込みなし
- 横スクロールの30分刻み行程表（ゲレンデ班／観光班切り替え）
- ページ上部の「次の行程」表示。日本時間で自動切り替え
- 訪問先の写真・説明は「訪問先の詳細を見る」で展開
- 実在の施設・観光地の写真に原典とライセンス表記。外部写真が失敗した場合は、風景イメージへ切り替え、その旨を明示
- お知らせを安全に編集できる `announcements.json` を追加
- 端末内だけで保存される持ち物チェック
- スマホの操作性、フォーカス表示、HTML構造、余白と文字サイズを調整

## VS Codeで見る

1. ZIPファイルを展開します。
2. `hokkaido-trip` フォルダをVS Codeで開きます。
3. `index.html` を選択して **Go Live** を押します。
4. ホーム・行程表・旅行ガイド・宿泊・安全のページを確認してください。

`index.html` を直接ダブルクリックして `file://` で開くと、ブラウザのセキュリティー制限により **お知らせJSONを取得できない場合があります**。Live ServerかGitHub Pagesから開いてください。

## GitHub Pagesに反映する

1. https://github.com/ban-ikura/hokkaido-trip を開きます。
2. `Add file` → `Upload files` から、ZIP **ではなく展開した中身**をアップロードします。
3. 同名ファイルの更新を行い、`Commit changes` を押します。ブラウザ上で一括上書きがうまくできないときは、各ファイルの鉛筆ボタンから編集するか、VS CodeのGit機能を利用してください。
4. `index.html` はリポジトリの最上位に配置してください。
5. `Settings → Pages` でブランチが `main`、フォルダが `/(root)` であることを確認します。
6. https://ban-ikura.github.io/hokkaido-trip/ を再読み込みします。反映には数分かかる場合があります。

**アップロードが必要な主なファイル：** `index.html`、`guide.html`、`stay.html`、`safety.html`、`style.css`、`app.js`、`trip-data.js`、`announcements.json`、`favicon.svg`、`robots.txt`、`assets/winter-evening.webp`。

**以前の古いファイルがGitHubに残っている場合：** `script.js`、`announcements.js`、`notices.js`、古い `assets`、`docs` フォルダなどは必要性を確認して整理してください。特に未許諾のホテルPDFや個人情報を含む `docs` の公開は避けてください。現在の完成版ZIPにはそれらのPDFを含めていません。

## お知らせの追加

`announcements.json` をGitHubで開き、鉛筆マークから次の形式で編集し、`Commit changes` を押します。

```json
{
  "items": [
    {
      "date": "2026-11-20",
      "title": "旅行に関するお知らせ",
      "body": "詳細は学校からの最終案内を確認。",
      "important": true
    },
    {
      "date": "2026-11-15",
      "title": "一般のお知らせ",
      "body": "確認事項を掲載します。",
      "important": false
    }
  ]
}
```

タイトルと本文はテキストとして表示され、HTMLやJavaScriptとしては実行されません。**氏名・電話番号・部屋番号・健康情報をお知らせに書かないでください。** JSONの最後の要素に不要なカンマを付けないでください。

## セキュリティーと公開範囲

- **配布用しおりの内容と違う可能性**があります。正確な時間・会場は学校・旅行会社の最新案内で確認してください。
- GitHub Pagesの`Public`リポジトリは、**URLを知っている人以外も閲覧でき、ファイルのソースも公開**されます。`robots.txt`や`noindex`は検索エンジンへの依頼であり、認証・アクセス制限ではありません。
- **生徒・教員の名簿、住所、直接連絡先、部屋割り、個別のアレルギー情報は公開禁止。** ホテル提供PDFも掲載していません。
- 古いPDFを削除した場合でも、**Gitの過去のコミット履歴には残る可能性があります**。機微なデータを公開していた場合は、公開履歴からの除去や新規リポジトリへの移行を検討してください。通常のDeleteだけでは消せません。
- サイトには外部JavaScript、広告、アクセス解析、外部Webフォント、フォーム送信、Cookieはありません。
- 公開ページにContent Security Policy（CSP）・Referrer Policyを**HTMLのmeta**として設定しています。ただし、GitHub Pagesに任意のHTTPセキュリティーヘッダーを追加できないため、サーバーヘッダー同等の完全な保護ではありません。動的なタイムライン配置のため`style-src 'unsafe-inline'`は許可しています。
- 訪問地の実写画像はWikimedia Commons（`upload.wikimedia.org`）から読み込みます。画像配信先との通信が発生し、接続先にはIPアドレスなどの通信情報が伝わる可能性があります。画像の利用条件はフッターで確認できます。
- 持ち物のチェックとコースの選択はブラウザの`localStorage`に保存され、外部へ送信されません。
- GitHubアカウントには**2段階認証**の設定を推奨します。編集権限は必要な人に限定してください。

## フォントと画像について

Windows、Mac、iOS、Androidで表示可能な日本語標準フォントを優先使用。サイトにフォントファイルを同梱していないため、端末によって字形がわずかに異なります。

背景画像は生成された冬山の夕景イメージです。**実際に北海道の特定地点で撮影された写真ではありません。** 観光地・ホテルの写真はWikimedia Commonsの実写です。撮影者・ライセンス・出典は全ページのフッターに記載し、表示にあわせてトリミングしています。

## 編集が必要な場合

- 行程の変更：`trip-data.js`（日付・コースごとの `events` 配列）
- お知らせの更新：`announcements.json`
- 文字サイズ・色・余白：`style.css`
- 機能の調整：`app.js`
- HTMLのページ構成：`index.html` など

更新時はまずローカルのVS Code + Live Serverで表示確認し、その後GitHubへ反映してください。


## 画像が表示されない問題への修正（2026-10-21）

- CSS内に背景写真データを直接埋め込み。`assets` フォルダのアップロード漏れでも背景を表示できます。
- 行程表・訪問先・ホテルの実写写真をWikimedia Commonsから表示します。画像取得先の制限などで読み込めない場合は、内蔵の冬景色へ自動切り替えます。
- **代替画像は実際の施設の写真ではありません**。カード上にその旨が表示されます。
- 外部に接続できない場合でも、写真カードを空白にしません。
- **更新必須:** `style.css`, `trip-data.js`, `app.js` の3ファイル。GitHubのリポジトリ直下に上書きしてください。
- 実写写真をすべて確実に表示したい場合は、ライセンスを確認した実写真のファイルをGitHubに同梱する必要があります。この版は元写真をダウンロード済みではありません。
- 写真の原典リンクはフッターと訪問先カードにあります。
