## お知らせ履歴
- `announcements.json` の `items` に最新記事を先頭で追加します。
- 同じ日付の記事は登録順を保持。最新1件が表に表示され、残りは「過去のお知らせの履歴」に入ります。
- **履歴を残すため、古い記事は削除しないでください。** 過去の記事の改訂履歴は別途GitHubのコミットから確認できます。
- `date` は `YYYY-MM-DD`、`title` と `body` は文字列、`important` は true/false です。
- JavaScriptはお知らせをHTMLではなくテキストとして描画します。

## デザイン
- スクロールに連動するタイトル消去の距離を短縮。
- ページのネイティブスクロールバーを氷・雪の配色へ変更。オーバーレイスクロールバー環境では右側に補助的なスクロール位置インジケータを表示。
- 従来の横スクロール行程表、時刻／移動バーのクリック・タップでの詳細表示、写真・持ち物チェック機能を維持。

## 管理者向けお知らせ投稿（運用中）

- 専用ページ：**[admin.html](admin.html)**。共通パスワードでログインし、**新規お知らせ投稿だけ**ができます。
- 投稿項目はタイトル・本文・重要フラグのみ。編集・削除・行程表変更の操作はありません。
- パスワードを公開ファイルに保存せず、Cloudflare Worker の Secret で検証します。
- 投稿は Cloudflare D1 に追記され、公開サイトは従来の `announcements.json` と合わせて表示します。
- Cloudflare Worker／D1／共通パスワードは設定済み。ほかの管理者による投稿と表示も確認済み。
- 管理担当者による有効化の手順：[admin-backend/SETUP.md](admin-backend/SETUP.md)。
- 共通パスワードをGitHubやチャットに貼り付けないでください。

## 生徒写真の投稿・管理者承認（コード実装済み、Cloudflareの写真保存設定待ち）

- 生徒用写真ページ：**[photos.html](photos.html)**。生徒用コードなしで写真とコメントを投稿。Cloudflare Turnstileの安全確認で不正投稿を抑制し、サーバー側で照合する。
- 写真はブラウザで縮小してWebPに作り直し、EXIF等の元画像メタデータを除去。サーバーは静止WebPの構造を検証する。
- 未承認写真は非公開R2バケットに保存し、一般閲覧用APIから一切提供しない。
- 管理者の[admin.html](admin.html)で承認・却下・掲載取り消しができる。お知らせの編集・削除APIは追加しない。
- **顔が写った写真（自撮り・集合写真・反射を含む）は投稿・承認禁止。** 個人情報、無断転載、誹謗中傷、いじめ、差別、危険・迷惑行為も禁止。
- **顔の自動判定はありません。** 管理者が写真と投稿文を審査する。公開サイト自体はリンクを知らない人でもアクセス可能。
- **Cloudflare R2・D1テーブル・Turnstileの追加設定とWorker再デプロイが終わるまで写真投稿ボタンは無効のままです。**
- 初回の有効化：**[admin-backend/PHOTOS-SETUP.md](admin-backend/PHOTOS-SETUP.md)**。
