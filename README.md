# 北海道研修旅行2026 — ユーザー提供写真の仮割当版

## GitHub Pagesへの反映

1. ZIPを展開し、中の `index.html` と同じ階層にある全ファイルを確認。
2. `https://github.com/ban-ikura/hokkaido-trip` にファイルをアップロードする。
3. **Commit changes** を押す。
4. 数分後に `https://ban-ikura.github.io/hokkaido-trip/` を `Ctrl + Shift + R` で更新する。
5. `https://ban-ikura.github.io/hokkaido-trip/photo-review.html` で写真の仮割当を確認する。

## 写真について

- Google画像検索の画像6種類は出典と撮影場所を確認できていません。各行程の写真は**仮配置**です。
- オルゴール堂公式サイトの外観画像は施設が確認できていますが、**転載の許可は未確認**です。
- Google画像サムネイルは低解像度であり、外部リンクです。表示されない場合は、同梱された冬景色のイメージ写真が表示されます。
- 安定したオフライン表示のためには、著作権者から掲載許可を得た原画像を `assets/` に保存し、それぞれのパスを更新してください。
- このバージョンの画像割当と権利情報は `PHOTO-MAPPING.md` を確認してください。
- 外部の写真は現時点で公開に必要な再利用条件が確認できていません。**権利を確認するまでは公開用として確定しないでください。**

## 保護対象データ

このZIPには生徒氏名・部屋割り・個人連絡先・ホテルから提供された非公開PDFは含めていません。
